# Chess Academy

Шахматная школа: уроки по дебютам и матовым схемам, игра против бота (3 уровня со своим рейтингом), онлайн-партии с другом по ссылке, профиль, свои фигуры. Платные уроки покупаются через WebMoney (WMZ).

## Структура

```
server.js        сервер: оплата WebMoney, открытие уроков, онлайн-партии
engine.js        шахматные правила (общие для сервера и сайта)
lessons.json     платные уроки (отдаются только после оплаты)
public/index.html  сайт (бесплатные уроки встроены)
package.json
```

## Запуск

```bash
npm install
WM_SECRET=ваш_секретный_ключ npm start
```

Требуется Node.js 18 или новее. Сайт откроется на `http://localhost:3000`.

## Переменные окружения

| Переменная | Обязательно | Описание |
|---|---|---|
| `WM_SECRET` | да | Secret Key из настроек Merchant WebMoney |
| `WM_PURSE` | нет | Кошелёк получателя, по умолчанию `Z326768612767` |
| `PORT` | нет | Порт, по умолчанию 3000 |
| `DATA_DIR` | нет | Папка для `data.json` (покупки и доступ). На хостинге укажите путь постоянного диска |

## Настройка WebMoney Merchant

Для кошелька Z326768612767:

- включить приём платежей, задать Secret Key (тот же, что в `WM_SECRET`);
- Result URL: `https://ВАШ-ДОМЕН/api/wm/result`, метод POST;
- метод подписи: SHA256;
- включить предварительный запрос (prerequest);
- тестовый режим выключить (сервер его отклоняет).

Сайт должен работать по HTTPS.

## Цены

Один урок: $0.99, полный доступ: $2.59. Меняются в трёх местах: `PRICE` в `server.js`, `P1` и `PA` в `public/index.html`, текст на главной странице.

## Важно

- Хостинг должен сохранять `data.json` между перезапусками (постоянный диск), иначе купленный доступ пропадёт.
- Доступ к урокам привязан к браузеру покупателя.
- Рейтинг, профиль и свои фигуры хранятся в браузере игрока.
- Онлайн-партии хранятся в памяти сервера и пропадают при перезапуске.
- Тексты документов на сайте — заготовки, их нужно проверить у юриста.
