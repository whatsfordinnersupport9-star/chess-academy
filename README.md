# Chess Academy

Шахматная школа: уроки по дебютам и матовым схемам, игра против бота (3 уровня со своим рейтингом), онлайн-партии с другом по ссылке, профиль, свои фигуры. Платные уроки покупаются криптовалютой через Telegram-бот Crypto Bot.

## Структура

```
server.js          сервер: оплата Crypto Bot, открытие уроков, онлайн-партии
engine.js          шахматные правила (общие для сервера и сайта)
lessons.json       платные уроки (отдаются только после оплаты)
public/index.html  сайт (бесплатные уроки встроены)
package.json
```

## Запуск

```bash
npm install
CRYPTO_PAY_TOKEN=токен SITE_URL=https://ваш-домен npm start
```

Требуется Node.js 18 или новее. Сайт откроется на `http://localhost:3000`.

## Токен Crypto Pay

1. В Telegram откройте @CryptoBot → Crypto Pay → Create App.
2. Скопируйте API Token (вид `123456:AAxxxx`) и задайте его как `CRYPTO_PAY_TOKEN` в настройках хостинга. Никому не показывайте токен и не кладите его в репозиторий.
3. Для проверки без денег можно создать приложение в @CryptoTestnetBot и задать `CRYPTO_PAY_API=https://testnet-pay.crypt.bot/api`.

Как это работает: при нажатии «Открыть урок» сервер создаёт отдельный счёт в Crypto Pay на $0.99 или $2.59 (в долларах, оплата любой поддерживаемой криптовалютой). Покупатель оплачивает его в Telegram, а сервер сам спрашивает у Crypto Pay статус счёта и открывает уроки только после статуса «paid».

## Переменные окружения

| Переменная | Обязательно | Описание |
|---|---|---|
| `CRYPTO_PAY_TOKEN` | да | Токен приложения Crypto Pay |
| `SITE_URL` | рекомендуется | Адрес сайта с https, нужен для кнопки «Вернуться» после оплаты |
| `CRYPTO_ASSETS` | нет | Список разрешённых монет через запятую, например `USDT,TON` (по умолчанию все) |
| `CRYPTO_PAY_API` | нет | Адрес API (по умолчанию основной, для теста testnet) |
| `PORT` | нет | Порт, по умолчанию 3000 |
| `DATA_DIR` | нет | Папка для `data.json` (заказы и доступ). На хостинге укажите постоянный диск |

## Цены

Один урок: $0.99, полный доступ: $2.59. Меняются в трёх местах: `PRICE` в `server.js`, `P1` и `PA` в `public/index.html`, текст на главной странице.

## Важно

- Готовые ссылки на счета (`t.me/send?start=...`) для сайта не подходят: они не привязаны к покупателю и обычно оплачиваются один раз. Поэтому сервер создаёт счёт на каждый заказ.
- Хостинг должен сохранять `data.json` между перезапусками (постоянный диск), иначе купленный доступ пропадёт.
- Доступ к урокам привязан к браузеру покупателя.
- Рейтинг, профиль и свои фигуры хранятся в браузере игрока.
- Онлайн-партии хранятся в памяти сервера и пропадают при перезапуске.
- Тексты документов на сайте — заготовки, их нужно проверить у юриста.
